# 隐私与数据处理基线

本文件是公开版的隐私契约，后续实现必须与之同步。

1. 公开版不包含全桌面截图、MAC/QQ/微信采集、进程/目录深度扫描的代码路径。
2. 截图仅限游戏窗口，仅由具备权限的管理员主动触发，带冷却和审计。
3. 任何硬件标识如后续加入公开版，必须使用服务端盐的单向哈希，且单独开关；当前公开范围不采集 MAC/QQ/微信。
4. 原文数据不进入公开日志；日志不得写入私钥、会话密钥、完整报告或玩家文件内容。
5. 证据和审计必须有保留期与清理入口；默认建议不超过 30 天，最终默认值在实现时由配置确认。
6. 进服告知与服务器规则必须说明采集事项。静默客户端不能替代告知义务。
7. 处置应保留审计证据和申诉通道；统计告警不得单独触发永久封禁。
8. 新增采集项必须先更新 `PrivacyManifest`、本文件和公开范围说明，再进入实现。

当前骨架未实现任何采集逻辑，本文件是后续实现的约束，而不是对现有运行行为的描述。
