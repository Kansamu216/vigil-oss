# 数据处理

## 当前版本

| 数据 | 用途和留存 |
| --- | --- |
| Minecraft UUID、玩家名、会话和审计事件 | Vigil 服务端用于会话校验、记录判定结果和管理封禁。审计记录默认保留 30 天，实际期限取自 `audit.retentionDays`。封禁记录由服主管理。 |
| Mod ID、版本、文件名、大小和 SHA-256 摘要 | 配置了服务端信任指纹的 Vigil 客户端可在握手时上报这些字段，用于白名单校验。文件内容在客户端计算摘要。 |
| 连接 IP | Minecraft 服务端在建立网络连接时收到 IP。Vigil 当前的报告和审计表未接入 IP 采集。服务端或代理的日志留存由各部署方说明。 |

玩家进服后会收到会话校验、Mod 清单、实际审计留存期限和连接 IP 的说明。想查询或删除数据，可以通过部署方公布的渠道联系服主。在玩家连接前，部署方应在服务器介绍或入服说明中公布处理目的、实际留存期、可访问数据的人员和联系方式。

## 扩展采集的告知要求

游戏窗口截图、安装标识和 Vigil 专门记录连接 IP 的流程尚未接入。启用前须向玩家列出实际启用的数据项，并说明采集时机、用途、接收方、留存期限和查询或删除方式。

| 数据 | 范围与告知 |
| --- | --- |
| 游戏窗口截图 | 仅采集 Minecraft 渲染画面。每次请求展示请求方、用途及留存期限，由玩家明确选择同意或拒绝。拒绝或超时即结束请求。 |
| 安装标识（机器码） | 拟使用本地随机生成的安装标识。首次发送前说明标识来源、用途和留存期，并取得玩家明确授权。 |
| 连接 IP | 使用服务端在玩家连接时看到的来源地址。部署方在入服前说明 Vigil 是否记录该地址、记录目的和保存期限。 |
