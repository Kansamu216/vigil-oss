# 隐私与数据处理基线

本文件描述 Vigil 当前及后续实现必须遵守的数据处理约束。

1. 客户端只采集完成校验所需的最小事实，不上传与校验无关的文件内容。
2. Mod 文件哈希采用流式计算；报告只包含协议允许的字段和数量。
3. 截图范围限定为游戏窗口，由具备权限的管理员主动触发，并记录冷却与审计。
4. 日志不得写入私钥、会话密钥、完整报告、原始硬件值或玩家文件内容。
5. 证据与审计必须有保留期和清理入口；默认保留期不超过 30 天。
6. 进服告知与服务器规则必须说明采集事项，静默客户端不能替代告知义务。
7. 处置应保留审计证据和申诉通道；统计告警不得单独触发永久封禁。
8. 新增采集项必须先登记用途、字段、开关、留存和访问角色，再进入实现。

当前版本尚未实现客户端采集 Agent；本文不把规划中的采集能力描述为现有行为。
