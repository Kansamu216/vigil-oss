# 公开功能边界

Vigil OSS 只包含稳定、可审计、低侵入的能力。

## 包含

- 签名挑战、AES-GCM 会话、nonce 防重放和保活。
- Mod 清单、SHA-256、人工白名单与基础自身完整性。
- UUID/IP 封禁、基础审计。
- 管理员主动触发的游戏窗口截图。
- 默认保守的行为统计告警。

## 不包含

- 全桌面、多显示器、失败连拍等扩展取证。
- MAC、QQ、微信及同源账号关联。
- 进程、窗口标题、目录清单等深度扫描。
- 实验性注入检测、私有挑战策略和管理 API。

公开与私有版本使用相同的密码学和协议安全基线。裁剪的是采集面和运营能力，不是通过削弱加密制造差异。

所有自动处置必须达到服务端确证门槛；统计信号只用于告警和人工复核。
