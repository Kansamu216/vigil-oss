# 当前平台支持矩阵

| 构建目录 | Minecraft | 加载器 | Java | 当前阶段 |
|---|---|---|---:|---|
| `forge-1.20.1` | 1.20.1 | Forge | 17 | 独立构建骨架 |
| `forge-1.21.1` | 1.21.1 | Forge | 21 | 独立构建骨架 |
| `neoforge-1.20.4` | 1.20.4 | NeoForge | 17 | 独立构建骨架 |
| `neoforge-1.21.1` | 1.21.1 | NeoForge | 21 | 独立构建骨架 |
| `fabric-1.20.1` | 1.20.1 | Fabric | 17 | 独立构建骨架 |
| `fabric-1.21.1` | 1.21.1 | Fabric | 21 | 独立构建骨架 |

这些目录是六个独立 Gradle 构建，而非根构建的 subproject。这样可以让 Forge、NeoForge、Fabric 的工具链独立升级和回滚。

当前不承诺覆盖每个小版本。新增小版本前必须通过：

1. 公共核心单元测试。
2. 平台契约测试。
3. 开发端启动 smoke test。
4. 客户端/服务端协议互通测试。
5. 打包内容、JPMS 与依赖审查。

1.12.2 / 1.16.5 Bukkit+Forge 混合端不在当前实现范围。未来通过新增独立 adapter 接入，不向公共核心引入 Bukkit 类型。
